# 最小使用示例

## 1. 开始训练

```text
用户：今天练。
```

教练先读取档案、状态和计划，然后只确认会改变当天安排的信息：

```text
教练：昨晚睡眠怎么样？现在精神状态 1-10 分是多少？有没有异常酸痛或疼痛？
用户：睡了 7 小时，精神 7 分，没有疼痛。
```

## 2. 获得完整计划

```text
教练：今天进行全身 A。
1. 坐姿推胸：轻重量熟悉 1 组，正式 2 组，每组 8-12 次，RPE 6-7。
2. 坐姿划船：轻重量熟悉 1 组，正式 2 组，每组 8-12 次，RPE 6-7。
3. 哑铃罗马尼亚硬拉：先学习轨迹，正式 2 组，每组 8-12 次。
4. 箱式深蹲或腿举：正式 2 组，每组 8-12 次，以膝盖无痛为边界。
```

无历史数据时不提供虚假的精确重量，第一次训练用于建立基线。

## 3. 训练中按需调整

```text
用户：坐姿推胸一直有人占着。
教练：改用固定轨迹的器械卧推或哑铃卧推，仍做 2 个正式组。先用轻重量确认稳定和无痛。
```

其余计划不变。正常情况下无需逐组对话。

## 4. 训练后汇报

```text
用户：推胸 20 公斤 12 次、11 次，最后一组 RPE 7；划船 25 公斤两组各 10 次，RPE 8；硬拉动作不熟，只做了轻重量练习；腿举没做。总共 43 分钟，没有疼痛。
```

教练保存已知事实，缺少的数据保持为空，然后只给三部分复盘：完成情况、需要注意的信号、下一次调整。

## 5. 下一次衔接

下一次按顺序进行全身 B。动作建议引用最近一次可比较记录；停练、疲劳、疼痛或停滞时按 `SKILL.md` 的规则降级。
